OnDuty APK GitHub Files

Upload these files/folders to the root of your GitHub repository:

1) package.json
2) capacitor.config.js
3) .gitignore
4) .github/workflows/build-android-apk.yml

After upload:
- Go to GitHub -> Actions
- Open "Build Android APK"
- Click "Run workflow"
- After completion, download artifact: OnDuty-debug-apk
- Inside it you will find app-debug.apk
